以下3点は、異なる学校・異なる家庭から個別に収集された児童画です。共同授業・合同行事・共通の参考画像は確認されていません。

Drawing A — EV-018-A

1998-08-15 / 凪代市立東小学校 / Household A

保護者が初期聞き取り時に提出。

[ PARK ] ○ round foundation \ \ slope [ vending ] \ \ [ blue fence ] beyond: outside frame

Text description: Park foreground. A circular base is drawn near center. A road rises away from the park. A vending-machine-shaped rectangle is partway up. A blue fence appears higher. What lies beyond the fence is outside the drawing.

Drawing B — EV-018-B

1998-08-15 / 凪代市立北小学校 / Household B

別家庭から独立提出。

uphill / behind [ blue fence ] | [ viewpoint ] [ vending ] | v downhill [ PARK ] ○

Text description: View appears to be from a slope. A vending machine is closest. Below it is a park with a circular center shape. A blue fence edge appears behind/uphill. No building beyond it is visible.

Drawing C — EV-018-C

1998-08-18 / 凪代市立臨海小学校 / Household C

第三の家庭から後日提出。

[ triangular roof ] [ blue fence ] | v downhill [ vending ] | bend / lower area hidden

Text description: Foreground includes a triangular roof edge and blue fence. A slope descends away. A vending machine is farther down. The lower end of the slope disappears behind a bend; the park is not visible.
